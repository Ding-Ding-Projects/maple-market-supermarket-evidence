Public project description

Maple Market in progress.

Maple Market is an in-progress Roblox supermarket and resort architecture project.

Explore the planned vision of a three-floor supermarket with connected circulation, retail departments, an upper-floor cafe, and an adjacent resort designed around suite and bedroom spaces.

The current milestone shows installed structural resort architecture, including timber framing, floors, partitions, stairs, lift openings, sixteen suite spaces, and thirty-two bedroom spaces. Furnishings, equipment, booking features, complete facility operations, and final visual acceptance are still in progress.

This is a construction milestone, not a finished experience. Roblox publication, runtime acceptance, and hosted public publication have not yet been completed.

Maple Market 仍然係一個建造及驗證中嘅 Roblox 超級市場同度假村建築項目。體驗呢個三層超級市場嘅規劃方向，包括互相連接嘅通道、零售部門、頂層咖啡廳，以及旁邊以套房同睡房空間為核心設計嘅度假村。目前嘅里程碑展示咗已安裝嘅度假村結構建築，包括木結構、樓層、隔間、樓梯、升降機開口、十六個套房空間同三十二個睡房空間。傢俬、設備、預約功能、完整設施運作同最終視覺驗收仍然進行中。呢個係建造里程碑，唔係已完成嘅體驗。Roblox 發布、實際運行驗收同公開託管發布目前都未完成。
