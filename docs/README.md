# Maple Market evidence gallery

This directory contains the public GitHub Pages source for the privacy-reviewed construction evidence gallery.

The gallery contains every reviewed capture selected for this public bundle. It does not claim that the experience is published, playable, complete, or runtime-accepted. Sensitive interior views, account information, source code, operational receipts, and unrelated temporary investigations are excluded.

The source revision and image hashes are recorded in `provenance.json`.

The overview also includes a bilingual project description, a reviewed promotional thumbnail,
and a copy control that falls back to manual selection when secure clipboard access is unavailable.
